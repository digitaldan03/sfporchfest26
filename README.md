# SF Porchfest 2026 — Interactive Map

A mobile-first interactive map for SF Porchfest 2026, built with React + Vite.

**Live:** https://YOUR_USERNAME.github.io/sfporchfest2026

## Features
- Full mission district map with cross-street labels
- Tap any venue → bottom sheet slides up with full schedule
- 🔥 HOT / ⭐ BUZZ popularity badges from Spotify listener counts
- Direct Spotify track links for every act on the official playlist
- ★ curated picks filter
- Works on any phone, no app needed

## Dev

```bash
npm install
npm run dev
```

## Deploy

Push to `main` — GitHub Actions deploys to GitHub Pages automatically.
